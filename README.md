# Deutsch Memo

Application locale de vocabulaire allemand (React + Vite).

## Lancer sur Windows
1. Installer Node.js LTS.
2. Ouvrir ce dossier dans l'Explorateur, taper `cmd` dans la barre d'adresse.
3. Exécuter `npm install`, puis `npm run dev`.
4. Ouvrir l'adresse locale indiquée par Vite.

## Vérification linguistique
Le bouton de vérification interroge LanguageTool (orthographe allemande) et MyMemory (suggestion de traduction français-allemand). Une connexion Internet est nécessaire pour cette vérification. Les services publics peuvent être limités ou indisponibles, et leurs suggestions ne remplacent pas un dictionnaire fiable. Les données de vocabulaire restent stockées localement dans le navigateur.

## Sauvegarde
Dans Paramètres, exporter régulièrement le vocabulaire en JSON.
